Este site apresenta os conceitos básicos do HTML e CSS, duas tecnologias essenciais para o desenvolvimento de páginas na internet.

1. O que é HTML?

HTML significa HyperText Markup Language. É uma linguagem de marcação utilizada para estruturar o conteúdo de páginas da internet.

Com HTML podemos organizar textos, imagens, links, tabelas, listas e formulários.

2. História do HTML

O HTML foi criado por Tim Berners-Lee em 1991. Desde então, passou por diversas atualizações, tornando-se uma das principais tecnologias utilizadas na construção de sites.

3. Principais tags HTML

  • <h1> - Título principal
  • <p> - Parágrafo
  • <img> - Imagem
  • <a> - Link
  • <br> - Quebra de linha
  • <ul> - Lista não ordenada
  • <li> - Item de lista
  • <table> - Tabela
  • <form> - Formulário

5. O que é CSS?

CSS significa Cascading Style Sheets. É uma linguagem utilizada para estilizar páginas HTML.

Com CSS podemos modificar cores, fontes, tamanhos, espaçamentos e fundos.
